# noisyvoltuk.github.io

A links page with the occasional post. Plain [Jekyll](https://jekyllrb.com), built by GitHub.
Nothing to install, nothing to upgrade.

## Change the links

Edit `_data/links.yml`. Fill in a `url` to show a link; leave it empty to hide it.

## Write a post (only when I feel like it)

Add a file to `_posts/` named `YYYY-MM-DD-some-title.md`:

```
---
title: The thing I made
---

A few words, a photo or two.
```

Commit and push (or add the file in the GitHub web editor). It shows up under
"Now and then" a minute or two later. Dates only set the order and aren't shown.
If there are no posts, that section doesn't appear.

Copy `_posts/2026-11-27-sample-post.md` as a starting point. Images go in `images/`.

## Files

- `index.html`: the home page
- `_layouts/`: page templates (plain HTML)
- `assets/style.css`: all the styling
- `_config.yml`: title, intro line, author

The old Astro site is in the git history if it's ever needed.
