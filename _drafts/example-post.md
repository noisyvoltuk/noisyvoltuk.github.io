Files in `_drafts` are never published, so this is just a template to copy.

To publish a post, put a file in `_posts/` named like `2026-12-01-my-thing.md`,
with a title at the top like this one. The date in the file name only sets the order;
it isn't shown anywhere.

Images go in an `images/` folder:
